# Голда: вниз по лестнице

Нативный 2D-прототип на **Godot 4.4.1 / GDScript**, рендерер Compatibility.
Windows, Linux, macOS и Android, без сервера и интернета.

## Запустить

Скачай сборку для своей платформы из артефакта `platformer-prototype`
в [GitHub Actions](https://github.com/kniazkov/platformer/actions).
Либо открой `project.godot` в Godot 4.4.1 и нажми F6/F5.
Скачиваемые приложения не требуют установленного Godot.

- Windows: `Golda.exe`.
- Linux x86_64: `chmod +x Golda.x86_64`, затем `./Golda.x86_64`.
- macOS Intel/Apple Silicon: распакуй `Golda.zip`. Приложение без подписи и нотариализации;
  для своего доверенного тестового экземпляра разреши запуск в настройках безопасности macOS.
- Android: установи `Golda.apk`, разрешив установку из выбранного источника.
  Тестовая debug-подпись, ARM32/ARM64. Это не сборка для магазина.
  Android 6+ с OpenGL ES 3.0 — исходный ориентир Godot 4.4;
  реальный нижний предел и производительность нужно проверить на твоём телефоне.
  CI генерирует новый тестовый ключ: сборку из другого прогона может потребоваться
  установить после удаления предыдущей (локальный прогресс при удалении теряется).

## Управление

| Действие | Компьютер | Телефон |
| --- | --- | --- |
| Прыжок | Пробел, новое нажатие для каждого прыжка | Правая кнопка |
| Приседание | Удерживать ↓ или S | Левая кнопка |
| Ускорение | Удерживать Shift | Кнопка рядом с прыжком |
| Пауза | Esc или Ⅱ | Ⅱ |

Герой сам идёт вниз по лестнице. Собирай голду и энергетики, перепрыгивай ямы и шипы,
приседай под балками. От появляющегося сзади преследователя нужно оторваться ускорением.

В обычном уровне нужно собрать указанное число слитков и добраться до выхода.
Три попытки общие на всё прохождение. После третьего проигрыша кнопка «Повторить»
начинает новую карту первого уровня. На уровнях 5, 10 и 15 — босс:
прыгай и ускоряйся, чтобы приземлиться ему на голову. Три удара дают победу.
После 30 слитков голды в битве непрерывно растут скорости всех персонажей;
этот разгон пропадает после битвы. После победы над боссом повышается базовая скорость.

## Реализовано

- Случайная воспроизводимая лестница с изолированными секциями препятствий.
- Голда, энергетики, выносливость, погоня, два типа снарядов босса.
- Полный цикл 15 уровней, общий запас попыток, финал и рекорд.
- Русские меню и статистика, вкладка «Неудачные попытки» со списком.
- Пауза при потере фокуса, сохранение состояния мира раз в секунду и при сворачивании/выходе.
  При аварийном завершении возможен откат до секунды. Сохранение через временный файл и резервную копию.
- Простая синтезированная музыка и эффекты, временные персонажи с заменой на PNG.
- Сенсорное управление с одновременным удержанием нескольких кнопок.

## Настроить и собрать

Параметры движения — `scripts/balance.gd`, раскладка секций — `scripts/level_generator.gd`.
Замена персонажей описана в [assets/README.md](assets/README.md).
[Согласованное ТЗ](docs/GAME_SPEC.md) отделяет требования от численных решений прототипа.

Нужны Godot 4.4.1 и его export templates. Для Android дополнительно JDK 17,
Android SDK Platform 35, Build Tools 35.0.0, platform-tools и debug keystore;
укажи пути в Editor Settings → Export → Android.

```sh
godot --headless --editor --import --quit
godot --headless --script tests/smoke.gd
godot --headless --script tests/traversal.gd
mkdir -p build/windows build/linux build/macos build/android
godot --headless --export-release Windows
godot --headless --export-release Linux
godot --headless --export-release macOS
godot --headless --export-debug Android
```

## Проверки и ограничения

Проверяются переходы, попытки, сохранение, удар по боссу, финал, детерминизм генерации
и прохождение 30 карт автоматическим игроком на трёх ступенях скорости.
Это не доказательство проходимости всех возможных карт и сочетаний атак босса.
Внешний вид проверен рендерингом OpenGL в Linux; Windows/macOS/Android собраны,
но запуск на физических устройствах и удобство сенсорных кнопок ещё нужно проверить.

Это ранний игровой прототип: графика и звук временные, баланс требует игры руками.
Размеры и тайминги выбраны разработчиком. Атласов анимации, установщиков,
подписанных релизов и публикации в магазинах пока нет.
