# Замена персонажей

Добавь прозрачные PNG в эту папку:

- `hero.png` — герой;
- `boss.png` — босс;
- `chaser.png` — преследователь.

Они загружаются автоматически при запуске. Если файла нет, рисуется временный человечек.
Положение спрайта привязано к середине нижнего края. Герой отображается в рамке 34×68,
при приседании 34×34; босс — 54×78. Картинка растягивается в рамку,
а физические размеры остаются неизменными. Для прототипа используется один кадр;
анимационные атласы потребуют следующего изменения реализации.
После добавления файлов переимпортируй проект в Godot и пересобери приложения.
